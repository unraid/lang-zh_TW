:ud_settings_symlinks_plug:
> 設為「是」可在 `/mnt/disks/` 建立指向 `/mnt/remotes/` 的相容符號連結。
>
> 此選項用來相容仍使用舊掛載路徑的虛擬機器與 Docker 容器。建議將相關路徑對應改為 `/mnt/remotes/`；若不需要舊版相容性，請保持「否」。
:end

:ud_settings_remote_share_wait_plug:
> 設定陣列啟動後，在掛載遠端共享資料夾前等待的秒數。
:end

:ud_settings_specify_smb_vers_plug:
> 設為「否」時，會先嘗試不指定 SMB 版本來掛載遠端共享資料夾。
>
> 設為「是」時，只嘗試明確指定 SMB 版本的掛載方式。部分遠端伺服器需要指定版本才能掛載。

:ud_settings_debug_level_plug:
> 排除問題時，可選擇特定類別，增加 Unassigned Devices 的除錯日誌。
>
> - **無**：停用除錯日誌。
> - **udev 與熱插拔**：記錄 udev、磁碟偵測及熱插拔事件。
> - **重新整理和更新**：協助追查介面更新或無回應的問題。
> - **命令計時**：記錄命令執行時間，可能產生非常大量的訊息。
>
> **請只在排除問題時短暫啟用，避免系統日誌被大量訊息占滿。**
:end

:end

:ud_settings_smb_security_plug:
> 設定 SMB 共享資料夾的存取方式：
>
> - **已停用**：不透過 SMB 提供共享。
> - **公共**：允許公用讀寫，適用於裝置、遠端 SMB／NFS 共享及 ISO 掛載。
> - **私有**：啟用使用者認證，個別設定各使用者的讀寫權限。
> - **私有且隱藏**：與私有模式相同，但不在網路瀏覽清單中顯示共享名稱。
>
> **Windows SMB 簽署與認證**
>
> Windows 11 24H2 或更新版本若無法瀏覽公共共享，可能與 SMB 簽署及訪客存取限制有關。可在 Unraid 建立與 Windows 帳號同名且有密碼的使用者，並使用該帳號認證。
>
> 若使用 Microsoft 帳號，可先在 Unraid 建立有密碼的使用者，再於 Windows「控制台 → 認證管理員 → Windows 認證 → 新增 Windows 認證」填入 Unraid 伺服器名稱及帳號密碼。
>
> 原文也提供 <u><a href='https://techcommunity.microsoft.com/t5/storage-at-microsoft/accessing-a-third-party-nas-with-smb-in-windows-11-24h2-may-fail/ba-p/4154300' target='_blank'>調整 Windows 簽署設定的說明</a></u>；請先確認影響，優先採用保留簽署並使用帳號認證的方式。
:end

:ud_settings_case_sensitive_plug:
> 設定檔名是否區分大小寫。
>
> **自動**：讓支援此功能的用戶端（例如 Linux CIFS）告知 Samba 是否需要區分大小寫。Windows 通常不區分大小寫，因此效果類似「否」，但仍保留建立檔案時使用的大小寫。大型目錄可能因搜尋與比對檔名而降低效能。
>
> **是**：保留用戶端提供的大小寫，且存取時必須完全相符。可避免大型目錄的額外檔名搜尋，但部分 Windows 應用程式可能因此失敗。例如檔案名為 MyFile，程式卻嘗試開啟 MYFILE 時，便可能找不到檔案。
>
> **強制使用小寫字母**：將所有用戶端傳入的檔名（不限於新建檔案）轉為小寫，以小寫名稱儲存及存取。可讓 Windows 應用程式以不同大小寫尋找檔案，但目錄清單不會保留原本的大小寫。
:end

:ud_settings_nfs_security_plug:
> 設為「是」可透過 NFS 匯出未指派裝置。可使用公共讀寫存取，或套用自訂的私有存取規則；實際存取仍受檔案與資料夾權限控制。

:ud_settings_nfs_rules_plug:
> 每個 IP 位址的規則必須各占一行，最後一條規則也要以換行字元結束。
>
> 不可使用 `IP1,IP2(...)` 格式，Unraid 不會以這種格式產生 exports 檔案。
>
> 所有 NFS 規則預設都會加入 `async` 與 `no_subtree_check`。
>
> **注意：**
>
> * 公用共享的預設規則為 `*(rw,sec=sys,insecure,anongid=100,anonuid=99,all_squash)`。
> * 專用共享的預設規則為 `*(rw,sec=sys,insecure,anongid=100,anonuid=99,no_root_squash)`。
:end

:end

:ud_remote_server_test_plug:
> 測試遠端伺服器是否提供 SMB 或 NFS 共享，並檢查相關連接埠是否可連線。NFS 測試也會確認 Unraid 執行 `showmount -e <server>` 時是否能列出匯出項目。
>
> SMB 顯示為線上，表示其 SMB 連接埠可連線。NFS 顯示為線上，則需連接埠可連線，且 `showmount -e` 能列出共享；僅連接埠可連線、但沒有列出匯出項目時，此外掛可能仍無法使用該 NFS 共享。
>
> 例如 Synology 伺服器可以連線、但未列出匯出項目時，請依序確認：
>
> - **共享是否已匯出**：遠端伺服器需設定要透過 NFS 提供的資料夾。
> - **用戶端存取限制**：確認允許 Unraid 的 IP 位址或網段存取。
> - **NFS 服務是否啟用**：Synology DSM 可在「控制台 → 檔案服務 → NFS」檢查。
> - **防火牆與 RPC 通訊**：確認允許必要連接埠；NFS 通常使用 2049，RPC 通常使用 111。
> - **通訊協定版本**：使用 NFSv3 用戶端時，遠端伺服器也必須允許 NFSv3。
>
> 確認服務、匯出目錄及存取權限均正確後，再檢查 `showmount` 的結果。
:end
